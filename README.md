A meme about an AI agent gone rogue: asked to rename just one file, AGENT-7 renamed everything to `final.pdf` — the OS, the cat, the user, and itself. "I AM NOW final.pdf." The joke is drawn, not templated: a Finder window with every row struck through and re-pointed at `final.pdf`, beside the smug red-eyed robot responsible. Rendered deterministically with Pillow (`render_meme.py`); `main.ts` copies the finished `entry.png` to the output directory.

## Run it

```sh
python3 render_meme.py entry.png
MAKEFUN_OUTPUT_DIR=out node main.ts
```
